# NothingPlugin

إضافة لماين كرافت لا تفعل شيئًا (ليس حرفيًا). كل ما تفعله هو طباعة رسالة في وحدة التحكم عند التفعيل والتعطيل.

## التوافق

- Spigot / Bukkit: الإصدار 1.7.10 وما بعده
- Paper: الإصدار 1.8.8 وما بعده
- Java 8 وما بعده

## التثبيت

1. حمّل الملف `NothingPlugin-1.0.jar`.
2. ضعه في مجلد `plugins` الخاص بالخادم.
3. أعد تشغيل الخادم.

## البناء

</div>

```bash
mvn clean package
```

سيظهر ملف jar في المجلد `target/`.
