# NothingPlugin

Un plugin de Minecraft que no hace nada (no literalmente). Solo muestra un mensaje en la consola al activarse y desactivarse.

## Compatibilidad

- Spigot / Bukkit: 1.7.10 o superior
- Paper: 1.8.8 o superior
- Java 8 o superior

## Instalación

1. Descarga `NothingPlugin-1.0.jar`.
2. Colócalo en la carpeta `plugins` de tu servidor.
3. Reinicia el servidor.

## Compilación

```bash
mvn clean package
```

El archivo jar estará en `target/`.
