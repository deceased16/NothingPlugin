# NothingPlugin

Un plugin Minecraft qui ne fait rien (pas littéralement). Il affiche seulement un message dans la console à l'activation et à la désactivation.

## Compatibilité

- Spigot / Bukkit : 1.7.10 et plus
- Paper : 1.8.8 et plus
- Java 8 et plus

## Installation

1. Téléchargez `NothingPlugin-1.0.jar`.
2. Placez-le dans le dossier `plugins` de votre serveur.
3. Redémarrez le serveur.

## Compilation

```bash
mvn clean package
```

Le fichier jar se trouvera dans `target/`.
