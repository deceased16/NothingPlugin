# NothingPlugin

A Minecraft plugin that does nothing (not literally). It only prints a message to the console when enabled and disabled.

## Compatibility

- Spigot / Bukkit: 1.7.10+
- Paper: 1.8.8+
- Java 8+

## Installation

1. Download `NothingPlugin-1.0.jar`.
2. Put it in your server's `plugins` folder.
3. Restart the server.

## Build

```bash
mvn clean package
```

The jar will be in `target/`.
