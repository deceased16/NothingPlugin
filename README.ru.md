# NothingPlugin

Плагин для Minecraft, который ничего не делает (не буквально). При включении и выключении он только пишет сообщение в консоль.

## Совместимость

- Spigot / Bukkit: 1.7.10+
- Paper: 1.8.8+
- Java 8+

## Установка

1. Скачайте `NothingPlugin-1.0.jar`.
2. Положите файл в папку `plugins` вашего сервера.
3. Перезапустите сервер.

## Сборка

```bash
mvn clean package
```

Готовый jar появится в папке `target/`.
