# NothingPlugin

一个什么都不做的 Minecraft 插件（并非字面意思）。启用和禁用时，它只会在控制台输出一条消息。

## 兼容性

- Spigot / Bukkit：1.7.10 及以上
- Paper：1.8.8 及以上
- Java 8 及以上

## 安装

1. 下载 `NothingPlugin-1.0.jar`。
2. 将文件放入服务器的 `plugins` 文件夹。
3. 重启服务器。

## 构建

```bash
mvn clean package
```

生成的 jar 文件位于 `target/` 目录。
